# Generative Engine Optimization Notes

This site now includes a lightweight GEO baseline for public search and AI answer tools. The goal is clear discovery, not keyword stuffing.

## Added Public Discovery Files

- `robots.txt`: allows crawling and points to the XML sitemap.
- `sitemap.xml`: lists the homepage, main tabs, `llms.txt`, and project detail pages.
- `llms.txt`: gives AI tools a concise Markdown overview of the portfolio, projects, photography, articles, and public profile links.

## Added Page Metadata

- Canonical URLs.
- Meta descriptions.
- Open Graph and Twitter preview tags.
- JSON-LD `WebSite`, `Person`, `ItemList`, and project `CreativeWork` data.

## Maintenance

Update these files when major content changes:

1. `llms.txt` when projects, articles, public profile links, or the summary changes.
2. `sitemap.xml` when new project pages are added.
3. Project HTML metadata when a project title, description, thumbnail, or page path changes.
4. `Config/site.txt` when the visible last-updated line changes.

## Privacy Reminder

These discovery files are public. Keep private phone numbers, private addresses, hidden documents, client-confidential work, and private EXIF/GPS details out of them.
