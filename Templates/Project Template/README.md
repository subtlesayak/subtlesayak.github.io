# Project Template

Copy this folder into `Projects/`, rename it, replace the text and images, then add the new folder name to `Config/projects.txt`.

Create a matching HTML page by copying one existing project HTML file and updating its filename in `description.txt`.

Edit `card.txt` with a short label on the first line and a one-line card description on the second line. Add the folder to `Config/selected-work.txt` when it should appear before the regular project order.
