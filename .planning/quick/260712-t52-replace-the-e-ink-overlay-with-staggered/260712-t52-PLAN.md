# Region-Based E-Ink Refresh Simulation

## Goal

Replace the full-page grayscale overlay with staggered black/white waveform phases applied to visible content regions on page load, navigation, and interactive clicks.

## Research Basis

- Full updates drive every pixel and visibly flash; fast/partial updates affect changed pixels or a defined window.
- E-paper waveforms drive particles through multiple timed frames before settling.
- Fast/partial updates can leave ghosting and periodically require a global clearing update.

## Tasks

1. Select visible atomic text/media regions, deduplicate nested regions, and assign top-to-bottom delays with local timing variation.
2. Replace the global overlay CSS with multi-stage black/white region waveforms and a subtle settling/ghost phase.
3. Trigger refresh on load, internal navigation, and non-navigation interactive clicks while honoring the toggle and reduced-motion preference.
4. Bump all shared cache versions and validate syntax, target selection, click behavior, routes, and public deployment.
